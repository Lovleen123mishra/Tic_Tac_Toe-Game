🎮 Tic Tac Toe Game

This is a simple Tic Tac Toe game built using HTML, CSS, and JavaScript.

✨ Features

Two-player mode:

O → Player 1

X → Player 2

Detects winning patterns (rows, columns, diagonals).

Displays an alert message showing the winner.

Clean and responsive design using CSS.

🕹️ How to Play

Player 1 starts with O.

Player 2 plays with X.

Players take turns marking empty boxes.

The first player to match three in a row (horizontal, vertical, or diagonal) wins.

A popup alert announces the winner.

📂 Technologies Used

HTML – for structure

CSS – for styling

JavaScript – for game logic and interactivity
